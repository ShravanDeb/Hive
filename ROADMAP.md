# Roadmap

Hive's development roadmap. Priorities shift based on user feedback and technical requirements.

---

## Near-Term

Features actively being developed or planned for the next release cycle.

- [ ] Direct messaging between students
- [ ] Email digest notifications (weekly summary)
- [ ] Project update posts (milestones, progress)
- [ ] Team size tracking and open slot indicators
- [ ] Improved search with full-text query support
- [ ] Skill-based project recommendations on dashboard
- [ ] Profile completion prompts
- [ ] Project archive and completion status

---

## Mid-Term

Features requiring significant design and engineering work.

- [ ] AI-powered project recommendations
- [ ] AI project scoping assistant (generate descriptions, suggest skills)
- [ ] Skill assessment and verification system
- [ ] Team formation matching algorithm
- [ ] Calendar integration for events and deadlines
- [ ] Public profile pages and portfolio view
- [ ] Project activity feed and timeline
- [ ] Markdown support in project descriptions
- [ ] File attachments for projects
- [ ] Export user data (GDPR compliance)

---

## Long-Term

Visionary features that define Hive's future.

- [ ] Mobile applications (iOS and Android)
- [ ] Public API for third-party integrations
- [ ] University partnership portal
- [ ] Analytics dashboard for project leads
- [ ] Global hackathon network and sponsorships
- [ ] Integrated video calls for team syncs
- [ ] AI-powered code review and collaboration tools
- [ ] Marketplace for project resources and templates
- [ ] Multi-language support (i18n)
- [ ] Enterprise tier for university administration

---

## Principles

1. **Ship small, ship often.** Incremental improvements over large releases.
2. **Students first.** Every feature must serve a real student need.
3. **Performance is a feature.** Speed matters more than features.
4. **Security is non-negotiable.** Every change is reviewed for security implications.
5. **Simplicity wins.** The best feature is the one you don't need to build.

---

This roadmap is a living document. It will be updated as priorities evolve.
