# Support

## Getting Help

### Documentation

Start with the [README](README.md) for setup instructions, architecture overview, and environment configuration.

### Bug Reports

Found a bug? [Open an issue](https://github.com/ShravanDeb/Hive/issues/new?template=.github%2FISSUE_TEMPLATE.md) with:

- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Browser, device, and OS information

### Feature Requests

Have an idea? [Open a feature request](https://github.com/ShravanDeb/Hive/issues/new?template=.github%2FISSUE_TEMPLATE.md) describing the problem you're trying to solve, not just the solution you envision.

### Security Issues

Found a security vulnerability? **Do not open a public issue.** Follow the [Security Policy](SECURITY.md) to report it privately.

## Frequently Asked Questions

**Is Hive open source?**

No. Hive is proprietary software. The repository is public for visibility and contributions. See the [License](LICENSE) for details.

**Can I deploy my own instance?**

No. Hive is not available for self-hosting or deployment outside the official production environment.

**Can I contribute?**

Yes. See [Contributing Guidelines](CONTRIBUTING.md) for how to submit pull requests.

**Where is Hive hosted?**

Hive is deployed on [Vercel](https://vercel.com) with a [Neon](https://neon.tech) PostgreSQL database.
